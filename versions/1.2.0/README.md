# YXLand 1.2.0

YXLand 是面向 Minecraft Java Edition 1.12.2 的永久领地保护与 GUI 管理插件，重点适用于资源世界、生存世界、玩家基地、矿区、农场与模组机器区域。

## 1.2.0 核心规则

**领地额度只计算 X×Z 水平平面，不计算 Y 高度。**

玩家只需要选择两个方块作为矩形的两个角。两个方块即使处于完全不同的高度，YXLand 也只读取它们的 X、Z 坐标：

- 平面范围 = X方向格数 × Z方向格数
- 这个平面范围才会消耗领地额度
- Y 高度不会增加任何费用或额度消耗
- 创建成功后，该 XZ 矩形从 **Y=0 到 Y=255** 全部受到同一个领地保护

例如：选择两点后形成 `7 × 10` 的 XZ 矩形，则只消耗 **70 格领地额度**。无论第一点在 Y=20、第二点在 Y=150，最终仍然只消耗 70 格，而且该矩形从 Y=0 到 Y=255 都属于玩家。

## 核心特性

- 永久领地，不包含自动过期或世界重置清理。
- 两点式 XZ 圈地，Y 坐标完全忽略，固定保护 Y=0~255。
- 普通玩家默认 **70 格 XZ 平面领地额度**。
- 第一次 `/land` 自动启动 7 步新手教程，教程进度持久化。
- `/land tutorial` 或 GUI “新手教程”可随时重新学习。
- 世界 + Chunk 空间索引，保护事件不全量扫描所有领地。
- 玩家专属 `/land` 管理 GUI：自有领地 + 已加入领地、信息、显示边界、成员、角色权限、访问/环境权限、Home、传送、重命名、调整范围、转让、删除、日志。
- 玩家点击 GUI 中“显示领地边界”后，边界只发送给该玩家并自动结束。
- **实时圈地预览**：选好第一点后，移动即可看到高密度双层边线、四角/四边中点竖柱和屏幕中央面积/额度/冲突状态；大范围自动限点，避免无限粒子。
- **进入/离开领地提示**：跨越 XZ 边界时显示领地名、主人和面积；离开后提示进入野外，且只在实际跨方块/跨世界时判断。
- **权限预设模板**：完全私人、好友基地、公共参观、机器基地；应用前二次确认。
- **临时成员授权**：30分钟、1小时、3小时、12小时、1天；使用到期时间戳，不为每个临时成员创建独立调度任务。
- **模组服防绕过强化**：FakePlayer 默认拒绝、非玩家改方块保护、漏斗/矿车漏斗/自动库存跨边界阻断、掉落物被自动库存跨界吸取保护、发射器/投掷器跨边界保护。
- 基础免费平面额度 + Vault 金币购买永久额外平面额度 + 权限组额度。
- 领地数量、总平面额度、单块最大平面范围、最小边长、领地间距均可配置。
- Owner / ADMIN / MEMBER / VISITOR / PUBLIC 权限模型。
- 黑名单优先，支持禁止陌生玩家进入领地。
- 保护方块、容器、常见交互、桶、红石、实体、PVP、爆炸、火焰、液体、活塞、悬挂实体、多方块放置、玩家踩踏类方块变化与跨边界移动。
- 对模组机器使用 Bukkit/混合端暴露的方块交互和 InventoryOpen 事件进行保护。
- Dirty 标记 + 批量异步保存；版本号阻止旧异步快照覆盖新数据；关闭时使用写入屏障执行最终同步保存；临时文件 + 原子替换。
- 教程阶段与永久购买额度一起写入 `data.yml`，玩家重启后继续当前教程阶段。
- 数据加载失败时停止插件并禁止空数据覆盖原领地数据。
- Vault 通过反射 soft-hook；没有 Vault 时核心领地保护照常工作，仅额度购买不可用。
- 所有玩家可见文本保留 `§#RRGGBB` 语法，由服务器现有客户端模组负责渲染。

## 安装

1. 使用 Java 8 兼容的 Minecraft 1.12.2 服务端（Spigot/PaperSpigot；混合端需正确转发 Bukkit 事件）。
2. 将 `YXLand-1.2.0.jar` 放入 `plugins/`。
3. 可选：安装 Vault 和一个 Vault 经济实现，用于购买额外领地额度。
4. 启动服务器生成 `plugins/YXLand/config.yml` 和 `messages.yml`。
5. 修改 `worlds.enabled`，填入允许玩家圈地的实际世界名称，然后 `/land reload`。

默认配置只启用名为 `resource` 的世界；如果你的资源世界名称不同，必须修改该列表。

## 玩家圈地流程

1. 输入 `/land` 打开“我的领地”。第一次使用会自动开始新手教程。
2. 点击“创建新领地”，领取圈地工具。
3. 到领地第一个角，左键任意方块选择 A 点。
4. 到对角位置，右键任意方块选择 B 点。
5. **A/B 两点的高度可以完全不同；系统只记录 X、Z。**
6. 选择 A 点后，玩家移动时会实时显示高密度粒子框：水平边线默认每 1 格一个粒子并叠 2 层，四角与四边中点显示高亮竖柱；屏幕中央同步显示长×宽、面积、已用/总额度、剩余额度以及冲突/超限状态。
7. 右键确认 B 点后停止实时预览，并打开创建确认 GUI。
8. 确认页显示宽度×深度、XZ 平面格数、当前/剩余平面额度，并明确显示 `Y=0~255（不计额度）`。
9. 确认创建后，整个 XZ 矩形从 Y=0 到 Y=255 永久受到保护。

## 新手教程

第一次输入 `/land` 会自动启动教程；教程不会一次把所有说明刷出来，而是跟着玩家真实操作逐步推进：

1. **认识额度**：说明普通玩家默认 70 格，只计算 X×Z，Y=0~255 免费完整保护。
2. **第一点**：点击 GUI“创建新领地”领取工具，提示左键选择第一个角。
3. **第二点**：第一点完成后自动提示右键选择对角位置。
4. **确认范围**：第二点完成后解释宽度×深度、平面格数和全高度保护，再让玩家确认创建。
5. **管理中心**：创建成功后说明领地管理 GUI，并引导查看边界。
6. **设置 Home**：显示边界后，引导站到合适位置设置领地传送点。
7. **完成**：告诉玩家后续可用 `/land` 管理成员、权限、黑名单、扩建、转让等。

教程阶段会保存到 `data.yml`。中途退出服务器不会丢失进度；再次 `/land` 会继续提示当前步骤。

重新开始教程：

```text
/land tutorial
```

也可以在 `/land` 主 GUI 中点击“新手教程”。

## 领地管理 GUI

- **领地信息**：名称、世界、XZ 坐标、平面范围、成员等。
- **显示领地边界**：按需显示，默认 30 秒，仅当前玩家可见。
- **成员管理**：添加永久成员、切换 ADMIN/MEMBER/VISITOR、移除成员；临时成员也会显示在列表中，并显示剩余时间。
- **临时授权**：输入在线玩家后选择 30分钟/1小时/3小时/12小时/1天；到期自动失效，也可提前撤销。
- **角色权限**：破坏、放置、容器、交互、红石、桶、PVP、生物伤害、进入等。
- **权限模板**：一键套用完全私人、好友基地、公共参观、机器基地，并在覆盖当前权限前二次确认。
- **访问/环境**：PUBLIC 进入、爆炸、火焰、液体、活塞、黑名单。
- **传送/Home**：设置 Home 后从 GUI 或命令传送。
- **重命名**：通过聊天输入新名称。
- **调整边界**：进入专用重新选点模式，再二次确认；重新计算的仍然只是 X×Z 平面范围。
- **转让**：输入在线目标玩家并检查对方数量/平面额度上限，再二次确认。
- **删除**：危险操作二次确认。
- **操作日志**：记录领地关键管理变更。
- **成员可见性**：被邀请的成员会在自己的 `/land` 列表看到加入的领地，并按角色权限进入管理中心。
- **管理员搜索**：后台可按领地名、主人名、领地/主人 UUID 前缀检索。

## 实时圈地预览

选中第一点以后无需点击第二点就能预览最终范围。默认配置强调“明显、容易看清”：

- `edge-step: 1`：边界默认每 1 格一个粒子
- `edge-layers: 2`：水平边线叠 2 层
- 四个角显示高亮竖柱
- `midpoint-pillars: true`：四条边中点也显示竖柱
- `pillar-height: 12`：以玩家附近高度为中心向上下延伸
- 屏幕中央持续显示 `长 × 宽 = 面积`、已用/总额度、创建后剩余以及冲突/超限原因
- `max-edge-points` 对极端大范围进行限点，避免单玩家一次刷新制造无限粒子

这只是创建过程中的临时预览；创建后的“显示领地范围”仍使用管理 GUI 中的独立显示功能。

## 权限模板

管理中心 → **权限模板**：

- **完全私人**：成员、访客、陌生人全部关闭；环境自动化默认关闭
- **好友基地**：成员可建设/容器/红石，访客可基础交互，陌生人仅可进入
- **公共参观**：所有人可进入与基础交互，但陌生人不能建设、开容器或操作红石
- **机器基地**：成员可操作容器/机器/红石，陌生人禁止进入，内部液体/活塞允许

选择模板后必须再点一次“确认套用”，以防误覆盖已有自定义权限。

## 临时成员授权

管理中心 → 成员管理 → **临时授权**：

1. 输入在线玩家准确名称。
2. 选择 30分钟、1小时、3小时、12小时或1天。
3. 玩家立即获得 `MEMBER` 临时角色。
4. 到期时间保存在 `data.yml`；重启后仍按原到期时间计算。
5. 不会为每个玩家创建一个 Bukkit 定时任务；权限判断使用时间戳，因此大量临时成员也不会堆积 Scheduler。
6. 可在成员管理中提前撤销；已有永久 ADMIN 等更高权限不会被临时 MEMBER 降级。

## 模组服防绕过

默认配置会额外保护：

- FakePlayer：类名/名称特征 + 管理员可配置额外名称；默认不允许 FakePlayer 继承 `yxland.bypass`
- 漏斗、矿车漏斗及 Bukkit 暴露的自动库存转移不能跨不同领地或从野外跨入领地
- 自动库存从地面吸取掉落物时同样检查来源与目标领地
- 发射器/投掷器跨边界动作进行阻断
- 非玩家实体/机器通过 `EntityChangeBlockEvent` 修改受保护领地方块时默认拒绝

这些保护依赖混合端把对应模组动作转发为 Bukkit 事件。纯 Forge 机器若完全绕过 Bukkit 事件，需要为具体模组增加专门 Hook。

## 指令

- `/land` — 打开玩家领地 GUI；未完成教程时同时显示当前教程步骤
- `/land help` — 指令帮助
- `/land wand` — 获取圈地工具
- `/land create` — 根据已经选择的两个点打开创建确认
- `/land tp <领地>` — 传送到自己的领地
- `/land sethome <领地>` — 设置领地 Home
- `/land show <领地>` — 显示领地范围
- `/land buy` — 打开平面额度商店
- `/land tutorial` — 重新开始新手教程
- `/land admin` — 管理员 GUI
- `/land reload` — 安全重载配置
- `/land save` — 立即保存
- `/land debug` — 查看运行状态

## 权限

- `yxland.use` — 基础使用，默认 true
- `yxland.create` — 创建领地，默认 true
- `yxland.admin` — 管理员功能，默认 OP
- `yxland.reload` — 重载，默认 OP
- `yxland.bypass` — 绕过保护，默认 OP
- `yxland.group.vip` — VIP 额度组
- `yxland.group.svip` — SVIP 额度组

权限组可在 `config.yml -> limits.groups` 自定义并通过 priority 选择最高优先级匹配项。

## 默认额度

默认普通玩家：

- 最多 3 个领地
- **70 格 X×Z 基础平面额度**
- 单块最多 50,000 格 X×Z 平面范围
- 最小 4×4
- 不同领地之间至少 3 格空隙
- Y=0~255 全高度自动保护，不消耗额外额度
- 火焰蔓延默认关闭；液体与活塞可在领地内部工作，但不能跨越领地边界
- 单块领地最多索引 16,384 个 Chunk（技术安全上限，防止异常超大范围拖垮服务器）

示例权限组默认值：VIP 140 格基础平面额度，SVIP 280 格基础平面额度。都可以自行修改。

默认额度商店每份增加 1,000 格永久 X×Z 平面额度，价格 1,000 Vault 金币。所有值均可配置。

## 从 1.0.0 升级

`config-version` 当前为 3；从 1.0.0 升级时仍会执行原有的额度迁移规则。插件只会自动修改**仍然等于 1.0.0 原始默认值**的额度：

- 普通：10000 → 70
- VIP：20000 → 140
- SVIP：40000 → 280

如果管理员过去已经手动改过这些值，升级程序会保留自定义值，不强制覆盖。

原有领地本身已经采用 XZ 边界存储，因此升级后不需要转换现有领地坐标。

## 数据

默认数据文件：`plugins/YXLand/data.yml`

保存内容包括：

- UUID 领地主人
- 世界与 XZ 边界
- 成员与角色
- 临时成员角色与绝对到期时间
- 黑名单
- 角色 Flag
- 环境 Flag
- Home
- 操作日志
- 玩家永久购买的 XZ 平面额度
- 玩家新手教程当前阶段/完成状态

玩家数据均使用 UUID，不依赖玩家名称作为主键。

## 性能设计

- `findAt` 使用世界 + Chunk 候选集合，不遍历全服所有领地。
- 领地、额度、教程状态常驻内存，保护事件不读 YAML。
- 自动保存先在主线程创建脱离运行对象的快照，再异步写文件；旧版本快照会在真正落盘前再次校验版本。
- 一个统一 BoundaryVisualizer 周期任务同时管理已创建领地边界与实时圈地预览，不按玩家创建独立 Scheduler。
- 实时预览默认高密度显示，但通过 `max-edge-points` 限制极端范围；已创建领地边界仍按独立步长采样。
- PlayerMoveEvent 仅在玩家 X/Z 方块或世界发生变化时处理。
- 领地索引存在 16,384 Chunk 的单领地技术保护上限，避免异常坐标或管理员误操作产生超大索引。
- 玩家退出会清理选择、聊天输入、边界会话和传送冷却缓存；教程进度不会清理，因为需要跨登录恢复。

## 配置升级

启动和 `/land reload` 会将 JAR 中新增的默认配置节点补入现有 `config.yml`，并保留管理员自定义值。当前 `config-version: 3`。

## 构建

### 正常 Maven 构建

项目 `pom.xml` 使用：

- `org.spigotmc:spigot-api:1.12.2-R0.1-SNAPSHOT`
- Java source/target 1.8

有 Maven 和网络时：

```bash
mvn clean package
```

产物位于 `target/YXLand-1.2.0.jar`。

### 离线验证构建

仓库包含 `compile-stubs/`，只用于当前无 Maven/无网络环境下验证 Java 8 语法和 Bukkit API 调用结构：

```bash
./test.sh
./build.sh
```

`compile-stubs` **不会打进插件 JAR**。正常生产构建仍建议使用 Maven + 实际 Spigot 1.12.2 API 再做一次编译。

当前交付前测试 Harness 共执行 19 个核心回归测试，覆盖原有领地/额度/教程/保存逻辑，并新增实时预览、进出状态、权限模板、临时授权、序列化和模组防绕过决策。

## 已知限制

- 模组机器能否被 Bukkit 事件拦截，取决于 CatServer/其他混合端是否把对应模组交互转发为 Bukkit 的 PlayerInteractEvent / InventoryOpenEvent。纯 Forge 绕过 Bukkit 事件的特殊机器，需要针对具体模组增加 Hook。
- 当前默认持久化为 YAML。代码通过 Repository 接口隔离，后续可增加 SQLite/MySQL 后端，但 1.2.0 未内置数据库驱动。
- `§#RRGGBB` 为服务器现有模组提供的自定义显示能力，YXLand 原样保留字符串。
