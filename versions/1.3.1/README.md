# YXLand 1.3.1

YXLand 是面向 Minecraft Java Edition 1.12.2 的永久领地保护与 GUI 管理插件，重点适用于资源世界、生存世界、玩家基地、矿区、农场与模组机器区域。

## 1.3.1 核心规则

### 领地只按 X×Z 平面计算

玩家只选择两个方块作为矩形对角点。两个点的 Y 高度完全忽略：

- 额度 = X方向格数 × Z方向格数
- Y 高度不消耗额度、不参与扩建费用
- 创建后该 XZ 范围从 **Y=0 到 Y=255** 全高度永久保护

例如两个点形成 `7 × 10`，只占 **70 格**。即使一个点 Y=20、另一个点 Y=150，仍只占 70 格，整个 Y=0~255 都属于这个领地。

### 默认 70 格免费额度

普通玩家默认：

- 基础永久额度：**70 格 XZ**
- 最多领地：3
- 单块最大面积：50,000 格
- 最小尺寸：4×4
- 领地最小间距：3 格

VIP/SVIP 默认示例额度分别为 140 / 280，可在配置中修改。

### 扩建：每新增 1 格 = 1000 金币

1.3.x 的扩建是一次完整交易：

- 原领地 70 格 → 新领地 71 格：新增 1 格，收费 **1000 金币**
- 70 → 73：新增 3 格，收费 **3000 金币**
- 70 → 100：新增 30 格，收费 **30000 金币**
- 缩小领地：**免费，不退款**
- 面积不增加，只移动/改变形状且总面积相同：**不收费**

每个成功付费新增的格子，会同时永久增加 1 格“已购额度”。因此玩家把最初 70 格用满后，不需要先去额度商店再付一次钱：确认扩建时直接付款即可继续扩大。

例如玩家已用满 70/70：

```text
扩建到 73 格
新增：3 格
费用：3000 金币
确认成功后永久额度：73 格
已使用：73 格
剩余：0 格
```

以后即使把领地从 73 缩回 70，已经购买的 3 格额度仍然保留，可继续用于这块领地或其他领地；金币不返还。

额度商店也统一为 **1 格 = 1000 金币**，默认 GUI 提供 +1 / +5 / +10 格，避免出现比扩建更便宜的绕过购买方式。

## 1.3.1 视觉修正 + 1.3.x 交互能力

### 1. 新手教程：只保留“取消”和“完成后重学”

第一次 `/land` 会自动进入逐步教程。

教程进行中可随时：

```text
/land tutorial cancel
```

取消后：

- 立即停止教程提示
- 保存 `CANCELLED` 状态
- 以后再次 `/land` **不会自动重新启动教程**
- 不提供暂停/继续，避免阶段错乱
- 已取消教程不能通过普通玩家入口重新开启

只有真正完成全部教程的玩家，才可以：

```text
/land tutorial
```

从第一步重新学习。

GUI 的“新手教程”按钮也遵守同一规则：

- 未开始：开始教程
- 进行中：左键查看当前步骤，右键取消
- 已取消：显示已取消，不允许重新启动
- 已完成：允许重新学习

教程主流程：

1. 认识 70 格 XZ 免费额度与 Y=0~255 全高度保护
2. 点击“创建新领地”
3. 左键选择第一点
4. 移动查看实时绿色水平细线预览
5. 右键选择第二点
6. 在确认 GUI 查看面积/额度后创建
7. 创建成功后认识持续绿色细线边界、管理中心与 Home
8. 教程完成

每个进行中的教程提示都会明确显示 `/land tutorial cancel`。

### 2. 绿色水平细线持续显示领地边界（1.3.1）

1.3.1 把原来的“多层火焰 + 高柱”彻底移除，改为方案2：**单层绿色水平细线 + 四角轻微强化**。

正式领地、新建预览和扩建候选范围统一使用 `HAPPY_VILLAGER` 绿色小粒子：

- 只绘制 XZ 矩形最外围四条边
- 不填充领地内部
- 不生成任何竖向粒子柱
- 不生成四边中点柱
- 不叠第二层、第三层水平线
- 小/中型领地使用亚方块间距采样，让边界看起来更接近细虚线/光线
- 四个角只沿相邻两条水平边短距离加密，让闭合矩形更容易辨认
- 粒子只发送给当前查看玩家

边界采用**完全水平**方案，不根据草地、山坡、洞穴等地形上下起伏：

- 新建/扩建时，第一点选中的方块顶部高度会成为本次预览的固定 Y
- 第二点高度不会改变这个 Y
- 确认 GUI 打开后也保持同一水平面
- `/land show` / GUI 开启正式边界时，记录开启瞬间玩家所在 Y；之后跳跃或上下移动不会让边界跟着漂移

边界仍持续到以下情况之一：

- 玩家再次点击 GUI“领地边界显示”关闭
- 再次 `/land show <领地>` 关闭
- 切换显示另一块领地
- 玩家下线
- 插件关闭

显示状态不写数据库；玩家重新上线不会自动恢复旧显示会话。

### 3. 第二点选择后，确认阶段仍持续显示绿色选区

玩家选择第二点后，候选范围不会因为确认 GUI 打开而消失。

流程变为：

```text
第一点
↓
移动时实时预览
↓
第二点
↓
固定显示完整候选绿色水平细线边界
↓
创建/扩建确认 GUI
↓
确认成功：无缝切换为正式持续领地边界
取消：立即清除候选绿色细线边界
```

这样确认时仍然能回头看世界中的实际范围。

### 4. 扩建/缩小完整交互重做

管理中心 → **调整领地范围**，先进入独立信息页，而不是直接把玩家丢进选点模式。

信息页会显示当前领地名称、尺寸、X/Z 坐标、面积、Y=0~255 全高度保护、已使用/总/剩余额度、单格价格、计价示例、缩小不退款以及三步操作说明。

点击“开始调整”后：

- **旧范围**：较稀疏的绿色水平细线，不做角点强化。
- **新范围**：更密集的绿色水平细线 + 四角轻强化。
- Title 实时显示旧面积→新面积、增加/释放格数、费用、调整后额度以及冲突/超限状态。

第二点选完后，新范围绿色水平细线继续固定显示，并打开最终确认页。

### 5. 扩建最终确认页与交易安全

最终确认页会明确列出原尺寸/新尺寸、原面积/新面积、面积变化、新坐标、Y=0~255、单格价格、总费用、永久额度变化、调整后额度与重叠/间距/尺寸校验。

支持确认应用、重新选择和完全取消。确认时会重新读取原领地并重新校验范围和 Vault 余额后才扣款；如果扣款后边界应用异常，会恢复已购额度并尝试原额退款。

## 其他核心功能

- 永久领地，无自动过期/资源世界重置逻辑。
- `/land` 玩家领地 GUI：自有 + 已加入领地。
- Owner / ADMIN / MEMBER / VISITOR / PUBLIC 权限体系。
- 权限模板、临时成员、黑名单、Home/传送、重命名、转让、删除、操作日志。
- 进入/离开领地 Title 提示。
- Vault 永久额度购买。
- 管理员 GUI 与领地搜索。
- World + Chunk 空间索引。
- FakePlayer 默认拒绝。
- 漏斗/矿车漏斗/自动库存、发射器/投掷器、非玩家改方块、爆炸、火焰、液体、活塞等保护。

## 安装与指令

1. 使用 Java 8 兼容的 Minecraft 1.12.2 服务端。
2. 将 `YXLand-1.3.1.jar` 放入 `plugins/`。
3. 推荐安装 Vault + 一个 Vault 经济实现。
4. 启动后设置 `worlds.enabled`，然后 `/land reload`。

主要指令：`/land`、`/land wand`、`/land create`、`/land show <领地>`、`/land tp <领地>`、`/land sethome <领地>`、`/land buy`、`/land tutorial`、`/land tutorial cancel`、`/land admin`、`/land reload`、`/land save`、`/land debug`。

## 默认权限

- `yxland.use`
- `yxland.create`
- `yxland.admin`
- `yxland.reload`
- `yxland.bypass`
- `yxland.group.vip`

## 数据与性能

数据默认保存在 `plugins/YXLand/data.yml`，玩家主键均使用 UUID。保护查询使用 World + Chunk 空间索引；单领地最多索引 16,384 个 Chunk；边界/圈地预览/扩建预览共用统一 Scheduler；绿色细线有 `max-edge-points` 自适应硬限制；保存采用 Dirty + 异步快照 + 版本竞争保护 + 关闭写入屏障。
