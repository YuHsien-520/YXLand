# YXLand 1.4.0 更新内容

- 新增独立管理员系统领域 `AdminRegion`，不占玩家额度/数量且不收费。
- 系统领域允许不同优先级重叠；高优先级覆盖，INHERIT 继续向下，同优先级重叠禁止。
- 加入三态规则（继承/允许/禁止）、领域用途模板、主领域点、管理员 GUI、调整/删除/搜索/传送。
- 管理员可自由配置进入/离开 Title、Subtitle、ActionBar、聊天提示、显示开关、Title 时间与 RGB 文本变量。
- 保护链、玩家圈地判定、模组/FakePlayer/自动化保护与 YXLand API 全面接入 AdminRegion。
