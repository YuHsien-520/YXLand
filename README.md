# YXLand

Minecraft Java Edition **1.12.2** 永久领地保护与系统领域插件。

当前版本：**1.4.0**

## 仓库说明

本仓库按版本完整归档 YXLand。每个版本目录包含：

- 对应可安装 JAR
- 完整源码压缩包 `source.zip`
- 该版本 README
- 该版本 TEST_REPORT
- 独立 CHANGELOG
- SHA256 校验
- 完整源码文件清单

目录：

```text
versions/
├── 1.0.0/
├── 1.1.0/
├── 1.2.0/
├── 1.3.0/
├── 1.3.1/
├── 1.3.2/
├── 1.3.3/
└── 1.4.0/
assets/
```

> 当前历史版本中没有发现独立 PNG / OGG / OBJ 等客户端材质资源；如果以后 YXLand 通过 YXClientEngine 加入材质、音效或客户端资源，将继续按版本归档到 `assets/`。

## 核心规则

- 玩家领地只按 X×Z 平面计算额度，Y=0~255 全高度保护。
- 普通玩家默认基础额度 70 格。
- 扩建每新增 1 格默认 1000 金币，成功扩建会同步永久增加已购额度。
- 1.3.3 起：只使用真实 A/B 两点框选；选完后手持工具“蹲下 + 右键”进入确认。
- 1.4.0 起：新增独立 AdminRegion 管理员系统领域，支持优先级、三态规则与自定义进入/离开信息。

详细说明请查看 [`versions/1.4.0/README.md`](versions/1.4.0/README.md)。
